# Pinned analyzer versions for smartcontract-checker.
#
# The original download-tools.py ran, at run time and with shell=True:
#     pip install mythril
#     pip install oyente
#     pip install slither-analyzer
#     pip install smartcheck
#     pip install securify
#
# Five problems with that, all fixed here:
#
#   1. No version pins. The code fetched is whatever the index served at that
#      moment, so a rerun of the same command could install different code.
#   2. shell=True with an interpolated command string.
#   3. It installed into whatever interpreter happened to be active, which
#      is often the system or a shared tooling environment.
#   4. Two of the five names are not the upstream projects. As of this writing
#      `smartcheck` does not exist on PyPI at all (HTTP 404 on the simple
#      index) and `securify` exists as a project name with zero uploaded
#      files. `pip install smartcheck` therefore either fails or installs
#      whatever unrelated party registers under that name later. Both are
#      dependency-confusion surfaces: a future upload to either name would be
#      installed and executed by this tool.
#   5. The tool reported "All tools successfully installed." even when the
#      install had failed, because the success message sat inside the same
#      try block as the calls.
#
# The three analyzers that are genuinely distributed on PyPI are pinned below
# to exact versions. The sha256 of the released artifact is recorded for
# audit; it is not enforced with --require-hashes because that mode requires
# a hash for every transitive dependency as well, which needs a full lockfile
# generated by actually resolving the dependency tree.
#
# The other two are not on PyPI and are not pip-installed by this tool. They
# are installed from their upstream repositories at a pinned commit; see
# UPSTREAM_TOOLS in download-tools.py and the notes below.
#
# --- Upstream sources for the two tools that are not on PyPI ----------------
#
# smartcheck  https://github.com/smartdec/smartcheck
#             master @ 7b02010c4b4de20297c6daff5490dd374a796d55
#             install with:
#               pip install "git+https://github.com/smartdec/smartcheck@7b02010c4b4de20297c6daff5490dd374a796d55"
#
# securify    https://github.com/eth-sri/securify2
#             master @ 1913dfe797e512e549d02e97ce8ea467be73d3df
#             install with:
#               pip install "git+https://github.com/eth-sri/securify2@1913dfe797e512e549d02e97ce8ea467be73d3df"
# ---------------------------------------------------------------------------
